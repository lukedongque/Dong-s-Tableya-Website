# 🍫 Dong's Tableya Website

> **Status:** 🚧 Work in Progress (WIP)

A showcase and e-commerce landing page for **Dong's Tableya**, an artisanal brand celebrating Cebu's rich chocolate heritage through traditional 100% pure stone-ground cacao discs.

---

## 📌 Project Overview

**Dong's Tableya** brings the warmth of ancestral Filipino artisanry to the modern table. Made from premium native cacao beans crafted through generations of stone-grinding tradition, the website is being developed to offer customers an authentic, heritage-inspired digital storefront.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document layout (`<header>`, `<nav>`, `<main>`, `<section>`).
- **CSS3**: Custom layout and styling utilizing **Flexbox** and **CSS Grid**.
- **Typography & Fonts**:
  - **Host Grotesk** (Sans-serif) for clean, readable body copy and UI elements.
  - **Libre Caslon Text** (Serif) for classic, elegant headers and pricing.
- **Assets**: Custom SVG icons and high-resolution product photography.
